# FTB Ranks — Server Permissions Mod

[![Download Latest](https://img.shields.io/github/v/release/Ratiochiescalator/ftb-ranks-permissions-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Ratiochiescalator/ftb-ranks-permissions-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A lightweight permission and rank system for Forge servers with configurable commands per rank.

## Features

- Define custom ranks with permission node lists
- Assign ranks to players via /ftbranks command
- Time-limited rank assignments with expiry
- Works with FTB Quests for rank-gated rewards
- JSON config for simple server owner setup

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
